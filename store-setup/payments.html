Payments

The Payments tab configures Stripe, PayPal, and Cash on Delivery inside Kitbix Commerce. All inputs are sanitized by SettingsController::sanitizePaymentSettings(), then stored via PaymentManager::updateSettings().

Gateway overview

Gateway Type Key settings Code reference
Stripe Card (Elements / Payment Intents) Test mode toggle, publishable/secret keys per mode, webhook secret, statement descriptor. app/Services/Payment/StripeGateway.php
PayPal Redirect Mode (sandbox/live), client ID/secret per mode, webhook ID, auto-complete toggle. app/Services/Payment/PaypalGateway.php
Cash on Delivery Offline Title, description, delivery instructions, optional fee. app/Services/Payment/CashOnDelivery.php

Configuration workflow

  1. Open Kitbix Commerce → Settings → Payments.
  2. Toggle each gateway on/off. Toggled gateways add their ID to payment_methods so CartService can expose them.
  3. Enter credentials. Stripe requires keys for the active mode; PayPal needs client ID/secret per mode; COD supports optional instructions/fee.
  4. Save to persist payment_settings (per gateway array) and run currency validation. If the selected currency isn’t supported, the REST request fails with a 422.
  5. Run test checkouts: Stripe uses PaymentIntent IDs, PayPal redirects to approval URLs, COD immediately returns a pending status.

Tips & best practices

Tip: Store live credentials outside the database (constants or secrets manager) and inject them via filters if you need extra security.
Tip: Enable Stripe test mode while developing. The gateway exposes publishable + secret key pairs for each mode, simplifying sandboxing.
Tip: Document webhook endpoints. Stripe expects the Checkout URL provided in the UI, and PayPal uses the Webhook ID to verify signatures.

Common mistakes

  • Mixing sandbox and live credentials. Stripe/PayPal will reject charges and SettingsController will continue returning success, leaving orders pending.
  • Enabling gateways that don’t support the store currency. validateCurrencyGateways() throws an error, so nothing is saved.
  • Leaving PayPal webhook ID blank while auto-complete is enabled. Pending orders never flip to processing.
Reminder: Never expose secret keys on the frontend. Stripe’s publishable key is the only value returned by getClientConfig(). Keep secrets server-side.
