Getting Started

Installation Guide

Deploy Kitbix Commerce safely on staging and production using a repeatable process.

What you will cover

Installation can be scripted via WP-CLI or performed manually through wp-admin. Pick one method and document it so future upgrades remain predictable.

Step-by-step

  1. Download the latest release ZIP or pull the repository into your mu-plugins stack.
  2. Upload or copy kitbix-commerce into wp-content/plugins and ensure PHP can write to it.
  3. Activate the plugin and monitor wp-content/debug.log for fatals.
  4. If you track Kitbix in version control, commit admin/react-app/build so production servers do not need npm.
  5. Smoke-test REST endpoints with curl https://example.com/wp-json/kitbix-commerce/v1/ping.

Tips & best practices

Tip: Use wp plugin install kitbix-commerce.zip --activate in CI for reproducible logs.
Tip: Install on staging first and promote both code and database after verification.

Common mistakes

  • Double-nesting the plugin directory (wp-content/plugins/kitbix-commerce/kitbix-commerce).
  • Keeping aggressive cache/optimization plugins enabled during activation.
Reminder: If activation fails, WordPress disables the plugin automatically—fix the fatal, then reactivate to rerun installers.
