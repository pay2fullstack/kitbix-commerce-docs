Getting Started with Kitbix Commerce

Understand how Kitbix Commerce plugs into WordPress and which tasks to complete immediately after activation.

What you will cover

Kitbix Commerce is an opt-in layer on top of WordPress. It creates custom tables, REST routes, and a React admin SPA, so a short onboarding checklist keeps every environment stable.

Share this list with teammates and contractors so they can reproduce a healthy install on staging before touching production.

Step-by-step

  1. Upload or clone the kitbix-commerce folder into wp-content/plugins (or install the ZIP).
  2. Activate the plugin via Plugins → Installed Plugins to run migrations and seed addon metadata.
  3. Visit Kitbix Commerce → Dashboard once so the admin SPA bootstraps configuration and nonces.
  4. Create WordPress pages for Shop, Product, Cart, and Checkout and drop in the documented shortcodes.
  5. Flush permalinks (Settings → Permalinks → Save) to expose REST routes under /wp-json/kitbix-commerce.

Tips & best practices

Tip: Bookmark the dashboard URL in your internal runbook to keep onboarding consistent.
Tip: Capture the REST base URL and nonce from dev tools if you plan to automate smoke tests.

Common mistakes

  • Skipping the dashboard visit, preventing addon installers from executing.
  • Installing Pro addons before the free plugin is active.
Reminder: Uninstalling Kitbix Commerce drops its tables—export orders and products before removing the plugin.
