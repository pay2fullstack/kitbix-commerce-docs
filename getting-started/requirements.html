Getting Started

Server Requirements

Verify hosting prerequisites before onboarding merchants or importing catalogs.

Step-by-step

  1. Run wp cli --info (or php -v) to confirm versions.
  2. Ensure wp-content/uploads and wp-content/plugins are writable by the web user.
  3. Verify cron events execute or configure a real cron hitting wp-cron.php.
  4. Hit /wp-json/kitbix-commerce/v1/ping over HTTPS to test permalinks and SSL.
  5. Allocate at least 256 MB RAM to PHP-FPM when importing large catalogs.

Supported stack

Component Minimum Reason
WordPress 6.3+ Uses modern REST routing and script modules.
PHP 8.1+ Typed properties and Fibers power queue workers.
Database MySQL 5.7 / MariaDB 10.4+ JSON columns + utf8mb4 indexes for product metadata.
Extensions curl, gd, intl, mbstring, zip Needed for payments, image resizing, and download bundling.

Tips & best practices

Tip: Enable OPcache and persistent object cache for faster admin tables.
Tip: Mirror PHP versions between CLI and web to avoid serialized payload mismatches.

Common mistakes

  • Ignoring DISABLE_WP_CRON=true—order emails never send.
  • Running on outdated MariaDB builds that truncate utf8mb4 titles.
Reminder: Do not install Kitbix on read-only hosting—addons create additional tables during bootstrap.
