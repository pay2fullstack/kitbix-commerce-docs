Addon Development

Build first-class Kitbix addons using the registry, hooks, and REST APIs.

What you will cover

Addons are PHP classes implementing KitbixCommerceAddonsAddonContract. They register metadata, settings, and bootstrap logic.

Step-by-step

  1. Create a namespaced class that defines id, definition(), settings fields, and bootstrap hooks.
  2. Register the addon via the kitbix_commerce_register_addons filter.
  3. Use AddonRegistry::getSettings() or REST endpoints to read stored options.
  4. Enqueue assets only when the addon is active.
  5. Write tests or manual smoke steps so upgrades do not break your addon.

Tips & best practices

Tip: Use the Digital Download addon as a reference structure (models, services, controllers).
Tip: Document settings and per-product fields so merchants know how to configure your addon.

Common mistakes

  • Running heavy logic on every request even when the addon is disabled.
  • Mutating global services instead of using provided hooks and filters.
Reminder: Namespace everything—class collisions with themes or plugins will break activation.
