    Documentation Philosophy

    Every page follows a predictable structure: concise overview, prerequisites, procedural steps, screenshots, best practices, and common mistakes. Whether you are a merchant or developer, you can skim to the right block and ship changes confidently.

    Tip: Bookmark /docs in your browser. All URLs use clean paths with index.html fallbacks, so the documentation works on shared hosting and is friendly to offline caches.

    Need help fast?

    1. Identify the relevant section (products, checkout, addons, etc.).
    2. Scan the "Common mistakes" block to avoid rework.
    3. Use the copy-ready commands/code snippets to apply fixes.
    Reminder: Keep production data backed up before altering database settings or running custom installers.
