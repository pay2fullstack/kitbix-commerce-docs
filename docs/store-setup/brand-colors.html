Brand Colors

Control the six color tokens Kitbix Commerce exposes as CSS custom properties. These values flow through kitbix_commerce_brand_style_attr(), so every shortcode adopts them without manual CSS edits.

Token reference

Field Storage key CSS variable Used in
Primary Color brand_primary --kitbix-commerce-primary Buttons, CTA backgrounds, active states.
Accent Color brand_accent --kitbix-commerce-accent Links, category filters, subtle highlights.
Success Color brand_success --kitbix-commerce-success Status badges (in stock, confirmations).
Danger Color brand_danger --kitbix-commerce-danger Error alerts, validation messages.
Muted Text Color brand_muted --kitbix-commerce-muted Helper copy, empty states, cart hint text.
Border Color brand_border --kitbix-commerce-border Card outlines, table dividers, form inputs.

Step-by-step

  1. Open Kitbix Commerce → Settings → Brand Colors.
  2. Enter hex codes (with #) for each token; the SPA validates via sanitize_hex_color().
  3. Save to persist values inside kitbix_commerce_settings.
  4. Reload storefront pages; shortcodes inject style="--kitbix-commerce-*: ..." automatically.
  5. Override or extend styles in your theme using the same CSS variables.

Tips & best practices

Tip: Match these tokens to your WordPress theme palette so embedded shortcodes blend seamlessly.
Tip: Use the muted/border tokens to maintain consistent contrast ratios in custom CSS.

Common mistakes

  • Forgetting the leading # in hex values—those entries fail sanitization.
  • Hardcoding colors directly in theme overrides instead of referencing the provided CSS variables.
Reminder: When cloning environments, copy kitbix_commerce_settings or the brand palette will fall back to defaults (#1d4ed8, #4338ca, etc.).
