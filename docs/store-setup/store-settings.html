Store Settings

The Store tab controls global currency, checkout math, and which gateways Kitbix exposes on the frontend. All values are persisted by SettingsController::sanitizeSettings() so shortcodes can read them in real time.

Field reference (Store tab)

Field Storage key Impact
Currency currency Used by kitbix_commerce_get_currency(), CartService, CheckoutTotals, and every shortcode template. Gateway list is filtered by supporters of this currency.
Enabled Payment Methods payment_methods[] Stores gateway IDs (stripe, paypal, cod). The SPA only shows toggled gateways, and CartService::availableGateways() hides anything missing here.
Checkout Tax Rate (%) checkout_tax_rate Converted to a decimal and injected into data-tax-rate on checkout.php so the JS totals widget can calculate taxes.
Flat Shipping Amount checkout_shipping_flat Passed to CheckoutTotals and surfaced in data-shipping-flat for client-side display.
Products per Page product_page_size Controls Product::publicPaginate() page size and the data-page-size attribute on the grid.
Product Pagination Type product_pagination_type Switches between infinite scroll, load more, or paged grids; validated to one of those three values.

How values flow through Kitbix

  • Shortcodes: Plugin::renderProductsShortcode(), renderCartShortcode(), and renderCheckoutShortcode() call kitbix_commerce_get_settings() before loading templates.
  • Checkout: checkout.php embeds tax and shipping defaults as data attributes so the React checkout component can calculate totals.
  • Validation: SettingsController::update() blocks negative tax/shipping values and ensures every enabled gateway supports the selected currency.

Recommended workflow

  1. Pick the store currency first, then toggle gateways that accept it.
  2. Enter realistic tax % and shipping flat-rate based on your fulfillment promise. Use decimals (15 for 15%).
  3. Set product pagination + page size to match your theme’s layout (e.g., 12 cards in a grid).
  4. Save changes and reload storefront shortcodes to confirm the new math.
  5. Trigger a sandbox checkout to verify CartService emits only the enabled gateways.

Tips & best practices

Tip: Document currency decisions in your ops runbook. Changing it later requires re-entering every product price.
Tip: Keep tax and shipping inputs positive whole numbers to match the SPA validation and prevent REST errors.

Common mistakes

  • Mixing unsupported gateways with the active currency (SettingsController will throw a 422 response).
  • Setting negative tax or shipping values; the REST call fails and nothing is saved.
Reminder: If you migrate environments, always clear any caching/plugin that might serve stale kitbix_commerce_settings or the storefront will show outdated currency and totals.
