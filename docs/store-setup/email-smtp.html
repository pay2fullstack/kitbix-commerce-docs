Email & SMTP

Use this tab to control checkout notifications, sender identity, and optional SMTP credentials. Values map directly to the fields sanitized in SettingsController::sanitizeSettings() and consumed by EmailNotificationService.

Field reference

Field Storage key Used by
Sender Name email_sender_name Header of all customer + owner emails sent through EmailNotificationService.
Sender Email email_sender_address wp_mail() from-address. Defaults to the WordPress admin email if left blank.
Owner Notification Emails email_owner_recipients Comma-separated list that receives owner notifications when toggled on.
Send order confirmation to customer email_send_customer_confirmation Determines if customers receive confirmation via sendCustomerOrderConfirmation().
Send new order notification to owner email_send_owner_notification Triggers sendOwnerOrderNotification().
Send customer email when order status changes email_send_status_updates Enables sendOrderStatusUpdate() when OrderController::updateStatus() runs.
Enable SMTP smtp_enabled If enabled, the plugin configures PHPMailer with the fields below before sending.
SMTP Host / Port / Encryption smtp_host, smtp_port, smtp_encryption Mapped to PHPMailer settings (ssl/tls/none).
SMTP Username & Password smtp_username, smtp_password Stored as-is (password left untouched if blank on save) and fed to PHPMailer auth.
SMTP From Address smtp_from_address Overrides WordPress defaults for services that require a verified sender.

Configuration workflow

  1. Open Kitbix Commerce → Settings → Email & SMTP.
  2. Set sender name/email and owner recipient list (comma-separated).
  3. Toggle which notifications should send (customer confirmations, owner alerts, status updates).
  4. If you need SMTP, flip Enable SMTP on and enter host, port, encryption, credentials, and optional from address.
  5. Save and use the Orders drawer (Resend Email) to verify deliverability in staging.

Tips & best practices

Tip: Use transactional providers like Mailtrap, Postmark, or SendGrid. Input their SMTP values directly; the plugin simply forwards them to PHPMailer.
Tip: Keep owner notification recipients to distribution lists (e.g., orders@domain.com) instead of personal inboxes so coverage is reliable.
Tip: Always test on staging first. SMTP errors are logged to error_log if PHPMailer throws.

Common mistakes

  • Leaving SMTP enabled without entering host/credentials—messages will fail silently.
  • Using Gmail/Outlook addresses without configuring App Passwords or allowing SMTP relays.
  • Disabling customer confirmations and forgetting to notify support, resulting in increased ticket volume.
Reminder: When cloning databases, scrub SMTP passwords or swap them for sandbox credentials immediately to avoid emailing real customers from staging.
