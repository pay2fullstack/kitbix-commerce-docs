Store Setup

Layout Settings

Choose which storefront templates render products, cart, checkout, and pagination. These values live in kitbix_commerce_settings and are read by every shortcode template inside public/templates.

Field map

Control Options Where it applies
Product Grid Layout Grid Showcase / Masonry / Spotlight product-grid.php passes the layout to kitbix_commerce_render_product_card(), changing card classes and hover states.
Product Detail Template Classic Details / Gallery / Story product-single.php loads different partial blocks and summary positions. Story mode auto-generates highlighted copy.
Cart Template Standard Summary / Compact / Minimal cart.php switches wrapper classes (kitbix-commerce-cart--*) so you can style condensed tables or full width carts.
Checkout Template Classic Steps / Modern / Split checkout.php adds kitbix-commerce-checkout--{template}; the React checkout mounts within that shell.
Product Pagination Infinite Scroll / Load More / Paged Controls data-pagination-type on the grid, which the frontend script uses to inject infinite scroll observers or numbered pagination.
Products per Page 1–50 items (default 12) Passed to Product::publicPaginate() and embedded in data-page-size for client-side fetching.

Step-by-step

  1. Open Kitbix Commerce → Settings → Layout.
  2. Choose a product grid + detail template that matches your theme’s columns.
  3. Select cart and checkout templates; preview the [kitbix_commerce_cart] and [kitbix_commerce_checkout] pages.
  4. Pick a pagination style and set Products per Page (the SPA enforces 1–50).
  5. Save, then reload storefront pages to verify new classes/styles took effect.

Tips & best practices

Tip: Override template files in your theme only after locking the layout choice; the selected option determines which classes your CSS should target.
Tip: Keep pagination consistent across environments to avoid unexpected behavior in cached JS bundles.

Common mistakes

  • Choosing pagination types that your theme overrides with conflicting JS (e.g., enabling infinite scroll while a theme forces numbered pagination).
  • Editing template files without mirroring the same layout option on staging—merchants will see different UI from what you tested.
Reminder: After changing templates, purge caches/CDNs and retest every shortcode page; stale HTML can mix old/new class names and break styling.
