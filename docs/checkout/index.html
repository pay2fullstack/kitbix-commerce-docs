Checkout Overview

Control cart behavior, form fields, payment gateways, and post-order workflows.

What you will cover

Kitbix keeps checkout lean: vanilla JS cart interactions backed by REST endpoints for totals and payments.

This section highlights the touchpoints shoppers experience before placing an order.

Step-by-step

  1. Review the cart and checkout shortcodes inside your theme for layout alignment.
  2. Configure payment gateways under Settings → Payments.
  3. Enable or disable checkout fields to match your fulfillment process.
  4. Test coupons, taxes, and shipping quotes on staging before launch.
  5. Place at least one real test order per gateway to confirm hooks and emails fire correctly.

Tips & best practices

Tip: Display trust badges or cutoff timers via addons to reduce friction.
Tip: Use browser dev tools to inspect REST responses when debugging checkout.

Common mistakes

  • Leaving sandbox keys in production gateways.
  • Hiding required address fields, causing carriers to reject shipments.
Reminder: Clear localStorage/cart caches between test runs to avoid stale data.
