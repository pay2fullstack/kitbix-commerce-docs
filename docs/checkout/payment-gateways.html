Payment Gateways

Configure bundled gateways or register custom ones with hooks.

Step-by-step

  1. Go to Kitbix Commerce → Settings → Payments.
  2. Enable the desired gateway and fill in API credentials.
  3. Confirm supported currencies align with your store currency.
  4. Configure webhook URLs so asynchronous events sync correctly.
  5. Place at least one order per gateway in sandbox mode before switching to live keys.

Bundled gateways

Gateway Mode Notes
Stripe Card (Elements) Supports SCA, saved payment intents, and webhooks.
PayPal Redirect Creates PayPal orders then returns to /checkout?paypal=return.
Cash on Delivery Offline Creates pending orders without instant payment.

Tips & best practices

Tip: Use the kitbix_commerce_payment_gateways filter to register custom providers.
Tip: Store live credentials in wp-config constants rather than the database when possible.

Common mistakes

  • Mixing sandbox and live keys, resulting in declined charges.
  • Ignoring webhook verification—status updates never arrive.
Reminder: Never log raw webhook payloads in production; scrub PII before persistence.
