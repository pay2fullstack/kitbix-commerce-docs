Cart Experience

The cart shortcode renders a responsive table with price, quantity, and total columns plus Empty Cart and Proceed buttons. Everything runs off public/templates/cart.php and the JS bundle that talks to the cart REST endpoints.

Template behavior

  • Template picker: The cart_template setting controls modifiers kitbix-commerce-cart--default|compact|minimal so you can style each layout @/wp-content/plugins/kitbix-commerce/public/templates/cart.php#7-60.
  • Table columns: Product, Price, Quantity, Total, and an action cell are hardcoded. JS fills tbody[data-kitbix-commerce-cart-body] after loading cart contents.
  • Total + badge: data-kitbix-commerce-cart-total and the “Taxes calculated at checkout” label mirror what you see in the screenshot.
  • Hooks: do_action('kitbix_commerce_cart_before_table') lets addons add reassurance UI (trust badges, urgency copy) before the table.
  • Buttons: Empty Cart triggers the REST delete endpoint; Proceed links to the checkout page resolved via kitbix_commerce_get_page_id('checkout').

Setup workflow

  1. Create a WordPress page (slug “cart”) containing [kitbix_commerce_cart]. The plugin auto-creates it on activation but you can move it anywhere.
  2. Under Settings → Layout, select the cart template variant that matches your theme spacing.
  3. Add CSS in your theme targeting .kitbix-commerce-cart and the modifier class if you need to tweak typography or table borders.
  4. Preview with products in the cart. Confirm totals update when you change quantity, and that the Empty Cart + Proceed buttons match your design system.
  5. Capture a screenshot (like the one above) for ops docs so teams know what “good” looks like after future edits.

Tips & best practices

Tip: Use the hook before the table to drop in policies, shipping cutoffs, or addon widgets instead of editing the template directly.
Tip: Keep “Taxes calculated at checkout” accurate—if you charge tax in-cart, update the copy via translation filters.

Common mistakes

  • Hardcoding checkout URLs. Always pull kitbix_commerce_get_page_id('checkout') so multisite/localized URLs work.
  • Removing data-kitbix-commerce-cart-body or button data attributes, which breaks the JS controller.
Reminder: The cart JS persists data in localStorage; clear storage between theme overrides to avoid misreading regressions.
