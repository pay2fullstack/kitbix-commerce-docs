Product Schema & API

Every SKU in Kitbix Commerce free lives in the products table and exposes a predictable set of fields consumed by the admin SPA, REST API, and storefront shortcodes.

Categories & relationships

Products connect to multiple categories through the category_product pivot. The admin SPA syncs selections whenever you save.

  • Sync logic: Category::syncProductCategories() rewrites pivot entries every save @/wp-content/plugins/kitbix-commerce/app/Models/Category.php#232-259.
  • Manage categories: The modal in the SPA calls CategoryController endpoints for create/update/delete with nonce + capability checks @/wp-content/plugins/kitbix-commerce/app/Controllers/CategoryController.php#31-143.
  • Front-end filters: ProductController::publicIndex() accepts category IDs or slugs and returns filtered results with category arrays attached @/wp-content/plugins/kitbix-commerce/app/Controllers/ProductController.php#63-245.

REST endpoints to know

  1. GET /kitbix-commerce/v1/admin/products → uses index() with pagination, search, status, and categories.
  2. POST /kitbix-commerce/v1/admin/products → store() sanitizes payloads, sets timestamps, and fires kitbix_commerce_product_saved.
  3. PUT /kitbix-commerce/v1/admin/products/{id} → update() persists edits and resyncs categories.
  4. GET /kitbix-commerce/v1/products → publicIndex() powers the storefront grids, including search box + “All categories” filter.

Tips & best practices

Tip: Keep slugs immutable after launch so existing permalinks (and the single-product shortcode) never break.
Tip: Bulk edits should go through the REST endpoints above so hooks and category syncing fire consistently.

Common mistakes

  • Skipping category assignments; the storefront filter drop-down only lists categories that have products attached.
  • Publishing with zero stock and forgetting to restock—the product grid will still display “In stock (0)” until you update.
Reminder: There are no hidden product types in the free plugin. Everything is a simple SKU with optional addon meta. Keep documentation focused on these fields.
