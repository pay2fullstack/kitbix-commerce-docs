Simple Products

The free Kitbix Commerce plugin treats every item as a “simple” SKU with name, description, price, gallery, stock, status, and categories. There are no hidden product types or variation editors.

Editor fields

Field UI location Behavior
Name Top of the form Required. Saved into products.name and reused for the slug if you leave the slug blank.
Description Rich text editor HTML stored via wp_kses_post, rendered on product cards and detail page.
Price / Sale Price Pricing row Plain decimal inputs mapped to price and sale_price. There are no schedule fields—update manually when promotions start/end.
Stock Inventory row Integer quantity surfaced as “In stock (x available)” on the grid.
Status Dropdown near the save buttons published items show publicly; draft stays hidden but editable.
Gallery Images Media picker row Stores an ordered array of URLs in products.gallery. First image becomes the thumbnail if “Image” is empty.
Categories Sidebar + “Manage Categories” modal Selections are passed as ID arrays and synced with Category::syncProductCategories().

Saving flow

  1. Hit “Add Product” or “Edit” from the admin list.
  2. Fill out the form shown in the screenshots (name, description, price, stock, gallery).
  3. Assign categories or open “Manage Categories” to create new nodes (CategoryController enforces unique slugs).
  4. Click Save/Update. The SPA calls ProductController::store() or update(), which sanitizes data, saves timestamps, and emits kitbix_commerce_product_saved.
  5. Reload the storefront grid to confirm the new card or edits render immediately.

Tips & best practices

Tip: Use descriptive slugs (e.g., combo-bean-bag) so product permalinks remain readable and friendly.
Tip: Keep sale price blank when not on promotion—templates automatically hide the strike-through price.

Common mistakes

  • Trying to upload variation data—the free plugin doesn’t have attributes/variations. Create distinct products instead.
  • Leaving the status on Draft and expecting it to appear on the storefront.
Reminder: REST imports overwrite gallery JSON and category pivots. Back up tables or run imports in staging first.
